# 安装

## 使用包管理器安装

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab value="pnpm">```bash pnpm add @ikenxuan/amagi ```</Tab>
  <Tab value="npm">```bash npm install @ikenxuan/amagi ```</Tab>
  <Tab value="yarn">```bash yarn add @ikenxuan/amagi ```</Tab>
  <Tab value="bun">```bash bun add @ikenxuan/amagi ```</Tab>
</Tabs>

## 系统要求

- Node.js >= 18.0.0
- 支持 ESM 和 CJS 两种模块系统

## 模块导入

<Tabs items={['ESM (推荐)', 'CommonJS']}>
  <Tab value="ESM (推荐)">```ts twoslash import amagi from '@ikenxuan/amagi' // 或使用别名 import Client from '@ikenxuan/amagi' ```</Tab>
  <Tab value="CommonJS">```js const amagi = require('@ikenxuan/amagi').default ```</Tab>
</Tabs>

## 子路径导出

除了主入口，amagi 还提供了一些子路径导出：

```ts twoslash
// Express 相关
import express from '@ikenxuan/amagi/express'

// Axios 实例
import axios from '@ikenxuan/amagi/axios'

// Chalk 终端颜色
import chalk from '@ikenxuan/amagi/chalk'
```

<Callout type="info">amagi 不依赖任何日志库：日志通过[事件系统](/docs/v7/usage/guide/events)暴露，接一个监听器就能按自己的格式落地。</Callout>
