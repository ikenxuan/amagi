# 小红书 API

小红书平台的所有 API 方法参考。

<Callout type="info">本页是 **SDK 方法**参考（7 个）。同一批端点的 **HTTP 形态**（路径、query 参数、响应信封、在线调用）见 [HTTP 端点参考](/docs/v7/usage/api/http/xiaohongshu) —— 那部分由 `packages/core/openapi.json` 生成，不手写。</Callout>

## 调用形式与单次请求配置

Client 中的绑定 Fetcher 使用 `client.xiaohongshu.fetcher.method(options, requestConfig?)`。第二个参数只作用于当前调用，并与 Client 的实例级请求配置合并；单次配置优先，`headers` 会单独合并。显式提供大写 `headers.Cookie` 时，它也会替换本次底层调用的 cookie 参数。

直接导出的裸 Fetcher 使用 `xiaohongshuFetcher.method(options, cookie?, requestConfig?)`。这里没有实例级配置，第三个参数会直接透传到当前请求。`amagi.xiaohongshuFetcher` 与该命名导出是同一个裸 Fetcher。

当第三个参数显式设置 `headers.Cookie` 时，第二个参数必须传入完全相同的字符串字面量。字段名严格区分大小写，请使用 `Cookie`，不要使用 `cookie`。

小红书接口签名通常需要从 cookie 参数读取 `a1`，因此不要把需要签名的请求强行改为空 Cookie；如需覆盖 Cookie，两处应传入同一个包含有效 `a1` 的字符串。

## Fetcher 方法

### fetchHomeFeed

获取首页推荐数据。

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
const result = await client.xiaohongshu.fetcher.fetchHomeFeed({
  cursor_score: '',
  num: 20,
  refresh_type: 1,
  note_index: 0
})
```

| 参数           | 类型     | 必填 | 说明                             |
| -------------- | -------- | ---- | -------------------------------- |
| `cursor_score` | `string` | 否   | 分页游标                         |
| `num`          | `number` | 否   | 获取数量                         |
| `refresh_type` | `number` | 否   | 刷新类型: 1=下拉刷新, 3=上拉加载 |
| `note_index`   | `number` | 否   | 笔记索引                         |

### fetchNoteDetail

获取单个笔记数据。

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
const result = await client.xiaohongshu.fetcher.fetchNoteDetail({
  note_id: '64xxxxxxxx',
  xsec_token: 'xsec_xxx'
})
```

| 参数         | 类型                  | 必填 | 说明     |
| ------------ | --------------------- | ---- | -------- |
| `note_id`    | `string`              | 是   | 笔记 ID  |
| `xsec_token` | `string`              | 是   | 安全令牌 |

<Callout type="info">`xsec_token` 可以从笔记分享链接中获取，格式通常为 `xsec_xxx`。</Callout>

### fetchNoteComments

获取笔记评论数据。

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
const result = await client.xiaohongshu.fetcher.fetchNoteComments({
  note_id: '64xxxxxxxx',
  xsec_token: 'xsec_xxx',
  number: 50
})
```

| 参数         | 类型     | 必填 | 说明                                   |
| ------------ | -------- | ---- | -------------------------------------- |
| `note_id`    | `string` | 是   | 笔记 ID                                |
| `xsec_token` | `string` | 是   | 安全令牌                               |
| `number`     | `number` | 否   | 想要的条数，默认一页（游标由翻页处理） |

<Callout type="info">
  v6 的 `cursor` 参数已由声明式翻页接管（修 #61：小红书的 string 游标与抖音的
  number 游标语义差异收敛在端点声明里），调用方只说明要多少条。
</Callout>

### searchNotes

搜索笔记。

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
const result = await client.xiaohongshu.fetcher.searchNotes({
  keyword: '关键词',
  page: 1,
  page_size: 20
})
```

| 参数        | 类型     | 必填 | 说明       |
| ----------- | -------- | ---- | ---------- |
| `keyword`   | `string` | 是   | 搜索关键词 |
| `page`      | `number` | 否   | 页码       |
| `page_size` | `number` | 否   | 每页数量   |

<Callout type="info">
  排序方式与笔记类型（v6 的 `sort` / `note_type`）由端点声明内部取默认值
  （综合排序、全部类型）。搜索 `search_id` 也由 `build` 显式生成，调用方不用管。
</Callout>

## 注意事项

<Callout type="warning">
  小红书接口对签名和 Cookie 要求较高，请确保： 1. Cookie 中包含有效的 `a1` 值 2. 正确传递 `xsec_token` 参数 3. 设置合理的请求间隔
</Callout>

- `note_id` 和 `xsec_token` 可以从笔记分享链接中提取
- 部分接口需要登录状态才能获取完整数据
- 小红书的反爬机制较为严格，建议控制请求频率
