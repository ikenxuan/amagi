# 响应类型

<Callout type="warn">
  **v7 移除了 `typeMode`。** v6 的 `typeMode: 'strict' | 'loose'` 是一个「写了
  两万六千行类型、默认却返回 `any`」的中间态。v7 只有一种模式：响应类型始终是
  端点声明里的具体类型，不需要任何参数开关。v6 代码里的 `typeMode` 参数可以直接
  删除（`npx @ikenxuan/amagi-codemod v6-to-v7 src/` 会自动删）。
</Callout>

## 一种模式：具体类型 + 判别联合

`success` 是唯一判别键。收窄之后 `data` 才可读；失败分支没有 `data`，只有 `error`：

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '' } })
// ---cut---
const video = await client.bilibili.fetcher.fetchVideoInfo({
  bvid: 'BV1xx411c7mD'
})

if (video.success) {
  video.data
  //    ^?
} else {
  // 失败分支：kind / code / message / platform 原文码都在 error 上
  console.error(video.error.kind, video.error.message)
}
```

## 稳定性承诺

响应类型是**实测快照** —— 按真实响应写下来的形状，不是平台的契约。因此：

- 平台**新增**字段不算破坏性变更（类型可能一时没有它）
- 平台**删除/ 改名**字段时，类型会随修复版本更新
- 每个响应类型都带顶层索引签名，读未声明字段返回 `unknown` 而不是编译错误

## 三条逃生舱

当类型与真实响应不一致时，按代价从低到高选：

### 1. 索引签名（读未声明字段）

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '' } })
// ---cut---
const result = await client.bilibili.fetcher.fetchVideoInfo({ bvid: 'BV1xx411c7mD' })

if (result.success) {
  // 未声明字段：类型是 unknown，自己收窄
  const extra = result.data['newFieldFromPlatform']
  if (typeof extra === 'string') console.log(extra.toUpperCase())
}
```

### 2. 显式泛型覆盖返回类型

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '' } })
// ---cut---
interface MyShape {
  data: { bvid: string; newField: number }
}

const result = await client.bilibili.fetcher.fetchVideoInfo<MyShape>({
  bvid: 'BV1xx411c7mD'
})

if (result.success) {
  result.data.data.newField
  //                ^?
}
```

### 3. 类型断言（最后手段）

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '' } })
// ---cut---
const result = await client.bilibili.fetcher.fetchVideoInfo({ bvid: 'BV1xx411c7mD' })

if (result.success) {
  const newField = (result.data as Record<string, unknown>).newField
  void newField
}
```

## 从 v6 迁移

| v6 写法                            | v7 写法                                       |
| ---------------------------------- | --------------------------------------------- |
| `fetchX({ ..., typeMode: 'strict' })` | `fetchX({ ... })`（删参数，类型本就具体）   |
| `fetchX({ ..., typeMode: 'loose' })`  | `fetchX({ ... })` + 需要时用上面的逃生舱     |
| `result.data`（未收窄）              | `if (result.success) result.data`             |
| `result.code`                        | `result.error.platform?.code ?? result.error.code`（失败分支） |
