## 它能做什么

- **覆盖四个平台**：抖音、B站、快手、小红书，收录了各平台主流的数据接口
- **两种用法**：在代码中直接调用方法，或用一行代码启动为本地 HTTP 服务
- **参数即时校验**：每个接口的参数都经 Zod 校验，漏填或填错会在请求发出前被指出
- **返回值格式统一**：无论哪个平台、哪个接口，返回的都是同一种结构。先判断 `success`，成功读取 `data`，失败读取 `error`
- **类型随接口而定**：返回值的类型即接口本身的类型，无需手动声明，也没有开关需要设置
- **内置常用工具**：签名算法、URL 拼接、AV/BV 号互转等
- **同时支持 ESM 与 CJS**
