> [!WARNING]
> **v7 预览版**：7.0.0 尚未正式发布（当前 beta），接口签名、返回类型与行为
> 仍可能随版本调整。生产环境请继续使用 v6 正式版，文档见
> [v6 文档（正式版）](/docs/v6)。

欢迎阅读 amagi v7 文档。v7 的核心变化：**声明式端点注册表 + 执行管线**
—— 一个接口一份声明，参数校验、HTTP 路由、fetcher 方法、签名与翻页全部
由声明派生；响应类型直接复用 v6 的实测快照类型（`ReturnDataType`）。
