# 快手 API

快手平台的所有 API 方法参考。

## 调用形式与单次请求配置

Client 中的绑定 Fetcher 使用 `client.kuaishou.fetcher.method(options, requestConfig?)`。第二个参数只作用于当前调用，并与 Client 的实例级请求配置合并；单次配置优先，`headers` 会单独合并。显式提供大写 `headers.Cookie` 时，它也会替换本次底层调用的 cookie 参数。

直接导出的裸 Fetcher 使用 `kuaishouFetcher.method(options, cookie?, requestConfig?)`。这里没有实例级配置，第三个参数会直接透传到当前请求。`amagi.kuaishouFetcher` 与该命名导出是同一个裸 Fetcher。

当第三个参数显式设置 `headers.Cookie` 时，第二个参数必须传入完全相同的字符串字面量；接口支持匿名时，请写作 `method(options, '', { headers: { Cookie: '' } })`。字段名严格区分大小写，请使用 `Cookie`，不要使用 `cookie`。

## Fetcher 方法

### fetchVideoWork

获取单个视频作品数据。

```ts
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
const result = await client.kuaishou.fetcher.fetchVideoWork({
  photoId: '3xqxxxxxx',
  typeMode: 'strict'
})
```

| 参数       | 类型                  | 必填 | 说明     |
| ---------- | --------------------- | ---- | -------- |
| `photoId`  | `string`              | 是   | 作品 ID  |
| `typeMode` | `'strict' \| 'loose'` | 否   | 类型模式 |

### fetchUserWorkList

获取用户公开视频列表。

```ts
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
const result = await client.kuaishou.fetcher.fetchUserWorkList({
  principalId: 'KPL704668133',
  count: 12,
  pcursor: '',
  typeMode: 'strict'
})
```

| 参数          | 类型                  | 必填 | 说明                   |
| ------------- | --------------------- | ---- | ---------------------- |
| `principalId` | `string`              | 是   | 用户主页 `principalId` |
| `count`       | `number`              | 否   | 每页数量，默认 `12`    |
| `pcursor`     | `string`              | 否   | 分页游标，首屏可传空串 |
| `typeMode`    | `'strict' \| 'loose'` | 否   | 类型模式               |

## 使用示例

### 获取视频信息

```ts
import amagi from '@ikenxuan/amagi'
// ---cut---
const client = amagi({
  cookies: {
    bilibili: '',
    douyin: '',
    kuaishou: 'did=xxx; ...',
    xiaohongshu: ''
  }
})

const result = await client.kuaishou.fetcher.fetchVideoWork({
  photoId: '3xqxxxxxx'
})

if (result.success) {
  console.log(result.data)
}
```

## 工具集

### URL 拼接器

```ts
// @noErrors
import { kuaishouUtils } from '@ikenxuan/amagi'

// 获取结构化请求描述对象
const request = kuaishouUtils.kuaishouApiUrls.videoWork({
  photoId: '3xqxxxxxx'
})
```

### `live_api` 签名

```ts
// @noErrors
import { kuaishouUtils } from '@ikenxuan/amagi'

const request = kuaishouUtils.kuaishouApiUrls.userInfoById({
  principalId: 'KPL704668133'
})

const signed = kuaishouUtils.sign.signLiveApiRequest(request, 'kwfv1=your_cookie_value')
```

## 注意事项

<Callout type="warning">快手接口需要有效的 Cookie，部分接口可能需要登录状态才能获取完整数据。</Callout>

- 快手的 `photoId` 可以从分享链接中提取
- 快手的 `principalId` 可以从用户主页或直播间 URL 末段提取
- 评论数据可能需要登录 Cookie 才能获取
- 建议设置合理的请求间隔，避免触发风控
