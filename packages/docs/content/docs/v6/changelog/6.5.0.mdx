# v6.5.0 变更日志

## 破坏性变更

### 移除全部已废弃的 API

v6.0 发布时标记为废弃（调用会抛出 `DeprecatedApiError`）的兼容 API，以及后续版本标记废弃的接口，自本版本起全部彻底移除，不再提供导入与类型导出。

**`getXxxData` 系列**

`getDouyinData`、`getBilibiliData`、`getKuaishouData`、`getXiaohongshuData` 已从包导出、Amagi Client 实例和默认导出的静态属性中移除。请改用对应平台的 Fetcher：

```typescript
import { bilibiliFetcher } from '@ikenxuan/amagi'

const result = await bilibiliFetcher.fetchVideoInfo({ bvid: 'BV123' }, cookie)
```

**平台旧版 `api` 命名空间**

`douyin` / `bilibili` / `kuaishou` / `xiaohongshu` 四个旧版 API 存根对象及其绑定工厂（`createBoundDouyinApi` 等）已移除，Amagi Client 实例上的 `client.平台.api` 属性同步移除。请统一使用 `client.平台.fetcher`。

**日志兼容模块**

`logger`、`httpLogger`、`initLogger`、`logMiddleware` 已移除。v6 已改用事件驱动架构，请通过事件系统实现日志：

```typescript
import { amagiEvents } from '@ikenxuan/amagi'

amagiEvents.on('log:info', (data) => console.log(data.message))
amagiEvents.on('http:response', (data) => console.log(data.statusCode, data.url))
```

**其他移除项**

- `amagiClient` 别名：请使用 `createAmagiClient` 或默认导出
- `fetchDynamicCard` 及配套内容：B站官方已删除 `dynamic_svr` 接口，本次移除 Fetcher 方法、HTTP 路由 `GET /fetch_dynamic_card`、`bilibiliApiUrls.getDynamicCard`、返回类型 `BiliDynamicCard` 及相关的参数校验与方法名映射
- `ApiResponse<T>` 类型别名：请使用 `Result<T>`
- 内部废弃管理模块（`utils/deprecation`）随上述 API 一并移除

完整的迁移方式请参考 [v6 迁移指南](/docs/v6/usage/migration-v6)。
