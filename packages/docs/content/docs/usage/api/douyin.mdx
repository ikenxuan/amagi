# 抖音 API

抖音平台的所有 API 方法参考。

## 调用形式与单次请求配置

Client 中的绑定 Fetcher 使用 `client.douyin.fetcher.method(options, requestConfig?)`。第二个参数只作用于当前调用，并与 Client 的实例级请求配置合并；单次配置优先，`headers` 会单独合并。显式提供大写 `headers.Cookie` 时，它也会替换本次底层调用的 cookie 参数。

直接导出的裸 Fetcher 使用 `douyinFetcher.method(options, cookie?, requestConfig?)`。这里没有实例级配置，第三个参数会直接透传到当前请求。`amagi.douyinFetcher` 与该命名导出是同一个裸 Fetcher。

当第三个参数显式设置 `headers.Cookie` 时，第二个参数必须传入完全相同的字符串字面量；接口支持匿名时，请写作 `method(options, '', { headers: { Cookie: '' } })`。Cookie 头的大小写不敏感（`Cookie` 与 `cookie` 等价），签名器与绑定 cookie 的覆盖均能识别。

## Fetcher 方法

### fetchVideoWork

获取视频作品数据。

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { douyin: '' } })
// ---cut---
const result = await client.douyin.fetcher.fetchVideoWork({
  aweme_id: '1234567890123456789'
})
```

| 参数       | 类型     | 必填 | 说明     |
| ---------- | -------- | ---- | -------- |
| `aweme_id` | `string` | 是   | 作品 ID  |

### searchContent

搜索内容。

```ts twoslash
import amagi from '@ikenxuan/amagi'
const client = amagi({ cookies: { bilibili: '', douyin: '', kuaishou: '', xiaohongshu: '' } })
// ---cut---
// 综合搜索
const result = await client.douyin.fetcher.searchContent({
  query: '关键词',
  type: 'general',
  number: 20
})

// 用户搜索
const userResult = await client.douyin.fetcher.searchContent({
  query: '关键词',
  type: 'user'
})

// 视频搜索
const videoResult = await client.douyin.fetcher.searchContent({
  query: '关键词',
  type: 'video'
})
```

| 参数        | 类型                             | 必填 | 说明              |
| ----------- | -------------------------------- | ---- | ----------------- |
| `query`     | `string`                         | 是   | 搜索关键词        |
| `type`      | `'general' \| 'user' \| 'video'` | 否   | 搜索类型          |
| `number`    | `number`                         | 否   | 获取数量          |
| `search_id` | `string`                         | 否   | 搜索 ID（分页用） |

### requestPassportQrcode

申请 passport 扫码登录二维码（v6 passport 原始封装）。

> ⚠️ **已废弃（@deprecated）**：新写法请用 `client.douyin.login.qrcode()` —— v7 会话抽象（取码 / 轮询 / challenge 由引擎编排，`expire_time` 秒转 `expiresAt` 毫秒）。此方法保留仅作兼容。

```ts twoslash
import { douyinFetcher } from '@ikenxuan/amagi'
// ---cut---
const result = await douyinFetcher.requestPassportQrcode(undefined, 'session cookie')
```
